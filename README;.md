                                           Bike Sales Analysis Dashboard 

Project Overview
This project focuses on analysing bike sales data using Microsoft Excel. The goal was to understand customer demographics, explore sales performance, and identify patterns that can support better business decisions.

Project Objectives
- Analyse customer demographics and purchasing behaviour.
- Examine bike sales performance.
- Identify patterns across different customer groups.
- Present insights through an interactive Excel dashboard.

Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Excel formulas

Key Areas of Analysis
- Customer demographics
- Customer purchasing behaviour
- Sales performance
- Sales patterns across customer groups

Dashboard
The dashboard provides a visual summary of the analysis, allowing users to explore the data and interact with different categories using slicers.

Skills Demonstrated
- Data analysis
- Data summarisation
- Data visualisation
- Dashboard development
- Business insight generation

Conclusion
This project demonstrates how Microsoft Excel can be used to transform raw sales data into meaningful information through analysis and interactive visualisation.
